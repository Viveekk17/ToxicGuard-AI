1. Project Overview

ToxicGuardAI detects, categorises and explains toxic comments in English, Hindi and Hinglish. A fine-tuned multilingual BERT predicts 6 toxicity categories, XAI shows which words drove each decision, and an LLM writes a plain-language explanation and a polite rewrite — in a deployed web app.

2. Problem Statement

  • Manual moderation does not scale to millions of comments.
  • Most detectors are English-only; Hindi and Hinglish slang is missed.
  • Deep models are black boxes — no reason is given for a flag.
  • Gap: multilingual + fine-grained + faithfully explained detection.

3. Objectives

  1. Fine-tune mBERT for 6-category toxicity in English, Hindi, Hinglish.
  2. Explain every decision at word level and measure faithfulness.
  3. Add sentiment, information extraction, topics and cloud translation.
  4. Integrate an LLM and deploy a working web app.

  • Classifier: bert-base-multilingual-cased, 6 sigmoid outputs, masked BCE loss (unknown labels ignored) with pos_weight
  • Thresholds: tuned per category on validation F1
  • Ensemble: original + English translation (max if abusive term, else mean)
  • XAI: Integrated Gradients + Occlusion + LIME → consensus, ERASER faithfulness
  • Sentiment: VADER · IE: spaCy NER + gazetteer · Topics: LDA
  • LLM: zero / few-shot / XAI-grounded prompts, JSON output

12. Key Highlights

  • Macro ROC-AUC 0.965 across 6 toxicity categories
  • 6-category macro F1 0.693 vs 0.640 for TF-IDF (+5.2 pts)
  • Toxic F1 87.9% · recall 90.3% (TF-IDF: 86.1% · 85.8%)
  • One model for 3 languages: F1 English 89% · Hindi 94% · Hinglish 76%
  • Faithful word-level explanations from 3 XAI methods
  • Deployed web app: batch upload, LLM explanations, polite rewrites

13. Applications

  • Social-media & comment moderation

14. Conclusion

A single fine-tuned multilingual BERT detects and categorises toxicity in English, Hindi and Hinglish (macro ROC-AUC 0.965, toxic F1 87.9%) and outperforms the TF-IDF baseline, with the largest gain on fine-grained categories (+5.2 macro-F1 pts). Hinglish is the hardest case (F1 76%) because of romanised spelling variation and limited training data. XAI and an evidence-grounded LLM make every decision transparent.

Future scope: more Hinglish and Indic-language data, sarcasm detection, real-time moderation.
